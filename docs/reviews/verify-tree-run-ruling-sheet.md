## 二、charter §4.7 增补草案（属主裁定文字，位置以 charter 现行结构为准）

拟增补一段（供裁定/改写）：

> **递归验证器身份与边界。** ygl-trees 的验证器生产线以「树形验证」为治理原语：叶节点复用七型检查器，
> 组节点以封闭聚合算子聚合子判定；每层真实 run + archive，`verdict_digest` 只覆盖判定字段，审计字段单列。
> **身份判据**：能对一条业务规范给出可复核的树形判定（含 `NEUTRALIZED`/`INFRA_BLOCKED` 显式态），且
> 归档可独立验签、可被外部引用；不要求绑定单一编排实现。**边界**：不引入任意表达式/脚本钩子；不承担
> pi 兼容层（WP-B 属 jf 仓）；发布门仍由 prepublish-guard + meta gate 把关。

上方文字为草案，涉及 charter 的修改须属主 + 双评审席按既有流程定稿；本单不替代 charter 正文。
