# @ygl/core-text

Pure text utilities (ngram, contentHash, clip, parseFrontmatter) and output formatting helpers (ok, bad, table, writeResult)

## Use this package

Import from `@ygl/core-text` when you need pure text utilities (ngram, contenthash, clip, parsefrontmatter) and output formatting helpers (ok, bad, table, writeresult).

## Grant scope

`validateScope(raw)` accepts an omitted or empty value as unattributed, or an exact `dept:<id>`, `bench:<id>`, `*`, or `restricted` key. Ids match `[A-Za-z0-9._-]{1,64}`. Invalid types, whitespace and unsupported forms throw an error carrying `rc:2`; the helper never resolves market membership or grants.
