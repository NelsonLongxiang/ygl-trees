## 数据流

```
                    ┌──────────┐
                    │  Agent   │
                    └────┬─────┘
                         │
          ┌──────────────┼──────────────┐
          ▼              ▼              ▼
    agent brief    agent match     research query
          │              │              │
          │         skill 命中          │
          │              │         source fetch
          │              │              │
          │              │         evidence add
          │              │              │
          │              │         claim add ──→ claim evaluate
          │              │              │         (决策模型校准)
          │              │         claim resolve
          │              │              │
          │              │         produce report
          │              │              │
          │              │         kb ingest ───→ 知识库
          │              │              │
          │              │         kb promote ──→ 技能
          │              │              │
          └──────────────┴────── agent match 下次命中
                                          │
                                          ▼
                                    知识闭环完成
```
